สรุปWorkshop-1

ข้อ 1 ระบบแนะนำตัว
const เป็นการประกาศตัวแปรค่าคงที่  และการเอาข้อมูลมาแสดงผลร่วม กับข้อความด้วย Template Literals เครื่องหมาย (` )เพื่อให้โค้ดอ่านง่ายและจัดรูปแบบได้สะดวกมากขึ้น

ข้อ 2 ชนิดข้อมูลและ typeof
ทำความเข้าใจเกี่ยวกับชนิดข้อมูล Data Types และการตรวจสอบประเภทของตัวแปร

ข้อ 3 ระบบเครื่องคิดเลขคะแนน
สร้างฟังก์ชันเบื้องต้น เพื่อใช้ในการรับค่าตัวเลขเข้ามาคำนวณทางคณิตศาสตร์
ข้อ 4 ระบบตัดเกรดจากคะแนน
ใช้เงื่อนไข if / else if ในการจัดหมวดหมู่เกรด และใช้ลูป for  of วนอ่านชุดข้อมูลคะแนนใน Array และดักจับข้อมูลขยะ (Edge Cases) เช่น คะแนนติดลบ หรือเกิน 100

ข้อ 5 ระบบสั่งอาหารและคิดเงินค่าอาหาร
ฝึกการใช้เงื่อนไขแบบ switch...case การเปรียบเทียบข้อความที่ตรงกันๆ ใช้ (===) มีการใช้ Fall-through เพื่อลดความซ้ำซ้อนของโค้ด และการคำนวณยอดเงินรวมจาก Object ของออเดอร์

ข้อ 6 ระบบจำลองการตรวจสอบสิทธิ์ Login
นำความรู้ทั้งหมดจากข้อ 1-6 มาสร้างระบบที่มีลอจิกซับซ้อนขึ้น เน้นความปลอดภัยโดยจัดลำดับการตรวจเงื่อนไขแบบ Early Return การ ตรวจ Username/Password ก่อนตรวจ role และใช้ ||, && และ === เพื่อตรวจสอบ
